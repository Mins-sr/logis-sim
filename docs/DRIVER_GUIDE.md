# ドライバー／運送事業者の入口

ドライバーは車両を選んで公開案件に参加します。配送計画の評価も関係者としての役割ですが、現在の画面では計画生成を管理者が操作します。

1. 管理者が起動したURLを同じ端末で開き、「ドライバーとして参加」を選びます。パスワード変更済みの場合はログイン欄を使います。
2. 「使用車両」から、自分に割り当てられた車両または未割当の車両を選びます。
3. 公開案件の「この車両で参加」を押し、処理結果と案件の状態を確認します。
4. 拒否された場合は案件・車両の最新状態を確認します。結果が不明な場合は、成功と決めつけず管理者と確認します。

利用可能な車両がない場合は管理者に確認してください。この入口から個別ユーザーや車両を新規発行することは想定していません。

役割変更は「役割を選び直す」から行い、同じブラウザのタブ操作は順番に完了させます。起動・停止は[管理者／ホスト／倉庫運営者の入口](ADMIN_GUIDE.md)を参照してください。

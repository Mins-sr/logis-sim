# 荷主の入口

荷主は配送案件の登録と状態確認を担当します。まず管理者に環境を起動してもらい、起動結果のURLを同じ端末で開きます。

1. 「荷主として参加」を選びます。デモログインに失敗した場合は、画面のログイン欄に現在の認証情報を入力します。
2. 荷主ポータルの案件市場で、集荷地点を入力して「案件を登録」を押します。
3. 処理結果と案件一覧の状態を確認します。受付直後はまだ適用が完了していない場合があります。結果が不明な場合は、重複登録を避けるため一覧を確認してから操作します。

現在の画面は簡易的な実験用入力です。詳細な契約・配送追跡の専用画面があることは前提にしません。表示される権限はサーバーの登録内容に従います。

役割を変えるときは「役割を選び直す」を使い、複数タブでのログインは順番に行います。環境の起動・停止で困った場合は[管理者／ホスト／倉庫運営者の入口](ADMIN_GUIDE.md)を参照してください。
